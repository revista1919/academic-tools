Guía Rápida para Empezar

1. Selecciona una plantilla y haz clic en "Generar Estructura" para crear un proyecto base.

2. Edita el preamble para agregar paquetes, el cuerpo principal para el contenido, y las referencias BibTeX.

3. Usa los botones de inserción para agregar elementos comunes rápidamente. Para imágenes, usa "Insertar Figura" - te pedirá seleccionar un archivo de imagen y lo insertará en el código.

4. Importa imágenes al insertar figuras; se guardarán localmente en memoria para compilación.

5. Compila para ver el PDF preview. Si no compila, verifica la consola para errores (puede faltar paquetes en la librería local).

6. Exporta como .tex o .zip completo.

7. Guarda versiones para restaurar cambios.

Nota: Para más flexibilidad, puedes editar el código directamente. Si import no funciona, verifica que los archivos en el ZIP tengan extensión .tex y .bib en minúsculas.
