Guía Rápida para Empezar

1. Selecciona una plantilla y haz clic en "Generar Estructura" para crear un proyecto base.

2. Edita el preamble para agregar paquetes, el cuerpo principal para el contenido, y las referencias BibTeX.

3. Usa los botones de inserción para agregar elementos comunes rápidamente. Para imágenes, usa "Insertar Figura".

4. Usa el diseñador visual de tablas y ecuaciones para crear contenido de manera intuitiva y generar el código LaTeX.

5. Usa atajos de teclado para inserciones rápidas (e.g., Ctrl-S para sección, Ctrl-T para tabla visual, Ctrl-Q para ecuación visual).

6. Conteo de palabras en tiempo real, buscar/reemplazar, y análisis de texto.

7. Exporta como .tex o .zip completo.

8. Guarda versiones para restaurar cambios.

Nota: Para más flexibilidad, puedes editar el código directamente.
