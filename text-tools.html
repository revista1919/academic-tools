Guía Rápida para Empezar

1. Selecciona una plantilla y genera la estructura base.

2. Edita en modo visual WYSIWYG como Word: texto enriquecido, imágenes (arrastra o inserta), tablas y ecuaciones visuales editables con doble click.

3. Inserta citas bibliográficas visuales (aparecen como (Autor, Año)) desde DOI/ISBN o .bib, editable con doble click.

4. Usa atajos de teclado (Ctrl-B negrita, Ctrl-S sección, Ctrl-Q ecuación, etc.).

5. Cambia a modo código para avanzado, con botones de inserción preservados. Exporta a ZIP estructurado LaTeX (con carpeta images) o compila online.

6. Conteo de palabras en tiempo real, buscar/reemplazar, versiones, auto-guardado cada 30s, análisis, y más UX: spellcheck, modales editables, sidebar extendida.

Nota de honestidad: Este editor prioriza claridad, previsibilidad y control del usuario por sobre compatibilidad total con LaTeX. Solo soporta elementos básicos (párrafos, secciones, listas, estilos simples, ecuaciones, tablas, figuras, citas básicas). Macros arbitrarios, clases personalizadas y layouts avanzados no se soportan y pueden perderse o aproximarse. Siempre se te informará de limitaciones o ambigüedades. La vista es continua (no paginada como Word real, ya que no es posible en navegador puro con Quill sin complejidad extrema; alternativa: usa impresión para ver páginas). Import de PDF limitado a texto plano (estructura/imágenes perdidas). Export a DOCX aproxima math como texto (no renders perfectos).
