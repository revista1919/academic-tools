# README.md

## Qué es Academic Tools

Academic Tools es un sitio web estático que ofrece herramientas académicas esenciales para estudiantes, investigadores, docentes y editores. Todas las herramientas funcionan completamente en el navegador, procesando datos localmente sin enviar nada a servidores externos.

## Para quién es

- Estudiantes universitarios que necesitan contar palabras, formatear referencias o unir PDFs.
- Investigadores que trabajan con matemáticas, LaTeX o revisión de papers.
- Docentes y editores que buscan utilidades éticas y gratuitas.

## Qué herramientas incluye

- **Texto y escritura**: Contador avanzado (palabras, caracteres, párrafos, citas), limpieza de texto desde PDF, corrección de saltos de línea, conversión texto a LaTeX y render visual.
- **Referencias y formato**: Formateador APA, Chicago, MLA; conversión entre estilos; generador de bibliografía; limpieza de referencias.
- **PDFs académicos**: Unir PDFs, reordenar páginas, selección de rangos, eliminar páginas en blanco, preview, renombrado automático.
- **Matemática y ciencia**: Render LaTeX en tiempo real, fórmula a imagen, editor de ecuaciones, conversor de unidades.
- **Revisión académica**: Verificador de estructura, detector de inconsistencias, control de longitud, checklist de envío.

## Principio de privacidad

Nada de lo que escribes o subes sale de tu computador. Todo el procesamiento es local en el navegador. No hay backend, cuentas ni tracking.
